# Database model

`supabase/migrations` is the schema source of truth. Four migrations create profiles, accounts, categories, transactions, budgets, projects, tasks and milestones; SQL reporting functions; idempotent owner setup; and atomic task reordering. Each personal row carries `user_id` and has RLS using `auth.uid()`. Composite foreign keys `(user_id, referenced_id)` prevent cross-owner references even for direct API callers.

Money uses `numeric(16,2)` with positive transaction amounts. Income and expense use one account and a matching category. Transfers use two distinct accounts and have no category or project. Budget months start on day 1; each owner has one budget per category and month. An expense category is required for budgets. Parent budgets include descendant category expenses. A separate month total function counts each underlying transaction once if parent and child budgets overlap. Deleting referenced accounts, categories or projects is restricted to protect financial history.

Balances are opening balance plus income minus expense plus transfers in minus transfers out. The opening balance date is account metadata and does not silently exclude transactions. Budget actuals and project actuals are sums of matching expenses. Transfers are excluded from income and expense reports. PostgreSQL performs all important sums as NUMERIC and returns text to avoid JavaScript floating-point rounding of aggregate results. Dates are `date` values passed as `YYYY-MM-DD`; timestamps are `timestamptz`.

The owner profile and default categories are initialized by an authenticated, idempotent SQL function. The migrations insert no sample transactions. `pnpm seed:local` is an explicit, idempotent example dataset for the embedded `.local-pg/` database only. Run `pnpm test:db` to validate migrations and database rules locally. Run `pnpm db:types` after applying migrations to a hosted project; it generates `src/types/database.generated.ts`. The checked-in `src/types/database.ts` is a local schema mirror used until hosted type generation is available.
